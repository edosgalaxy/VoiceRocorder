# Voice Recorder для Windows 11

Первая исходная версия многодорожечного диктофона с реверсом аудио.

## Возможности
- Последовательная запись отдельных голосовых дорожек.
- Выбор входного аудиоустройства.
- Запись в WAV (44,1 кГц, 16 бит, моно).
- Переворот аудио задом наперёд с сохранением оригинала.
- Прослушивание оригинала и перевёрнутой версии.
- Экспорт WAV.
- Автоматическое сохранение списка проекта.

Файлы проекта и записей хранятся в `Документы\VoiceRecorder`.

## Сборка
1. Установи .NET 8 SDK для Windows.
2. Открой `VoiceRecorder.sln` или папку проекта в Visual Studio 2022.
3. Восстанови NuGet-пакеты.
4. Нажми Build → Build Solution.
5. Запусти приложение.

Для публикации автономного EXE из папки проекта выполни в PowerShell:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

Готовый EXE появится в `bin\Release\net8.0-windows\win-x64\publish`.

## Примечание
Это исходный прототип. Перед повседневным использованием проверь запись и экспорт на своём микрофоне.
